# 前端设计规范

WorkAgent 的前端是**信息密集的控制台**，不是营销页。规范的目标不是好看，而是让几十个页面看起来像同一个产品，并且新人在没有设计师时也不会跑偏。

**约束力**：本文是 UI 实现的事实标准。新增界面、改样式、加组件前先读；规范没覆盖的新模式，先补规范再落地（与技术方案"文档先行"同一条规则）。

技术底座：`@douyinfe/semi-ui` + `web/src/styles.css`（近 2000 行，按区域分段）。不引入第二套 UI 库，不引入 Tailwind/CSS-in-JS。

---

## 1. 五条原则

| 原则 | 含义 | 反例 |
|---|---|---|
| **语义优先于样式** | 先问"这是什么状态/什么操作"，再决定颜色和重量 | 用主色表示"这个卡片好看" |
| **一个区域一个主操作** | 一屏/一个弹窗只有一个实心主按钮 | 底部两个 solid 按钮抢焦点 |
| **状态显式** | 加载/空/错误/禁用/只读都要有对应表现，不能白屏 | 列表为空时一片空白 |
| **复用而不是重画** | 插件视觉、弹窗、字段组、空态各只有一处实现 | 每个页面自己写一个 badge |
| **可访问性是硬指标** | 对比度、焦点可见、键盘可达不达标就是 bug | 图标按钮没有 `aria-label` |

## 2. 基础标尺

### 2.1 间距：4px 基准、8px 主节奏

所有间距从 `:root` token 取值，不写裸数字。命名即像素值：

```css
--wa-space-2: 2px;    /* 徽标内衬、图标与文字的最小缝隙 */
--wa-space-4: 4px;    /* 图标与文字、标签与徽标 */
--wa-space-6: 6px;    /* 标签与控件、紧凑列表行内 */
--wa-space-8: 8px;    /* 同级元素、卡片网格间隙 */
--wa-space-12: 12px;  /* 卡片内边距、列表行左右 */
--wa-space-16: 16px;  /* 面板内边距、字段组之间 */
--wa-space-20: 20px;  /* 弹窗内容区 */
--wa-space-24: 24px;  /* 页面区块之间 */
--wa-space-32: 32px;  /* 大区块、空态留白 */
```

用法：

```css
.card-grid { display: grid; gap: var(--wa-space-12); }
.dialog-group + .dialog-group { margin-top: var(--wa-space-16); }
```

**为什么**：8px 节奏让任意两个元素的距离可预测；4px 子步给密集列表留余地。现状里有 1/3/5/7/9/10/14px 这类值，遇到时按就近吸附（1→2、3→4、5→4 或 6、7→8、9→8 或 10、10→12、14→16），不要新增。

### 2.2 圆角：4 档 + 胶囊

| token | 值 | 用途 |
|---|---|---|
| `--wa-radius-4` | 4px | 徽标、标签、微型图标底 |
| `--wa-radius-6` | 6px | 输入框、按钮、下拉项 |
| `--wa-radius-8` | 8px | 面板、提示块、代码块 |
| `--wa-radius-10` | 10px | 卡片、可选块、对话框 |
| `--wa-radius-pill` | 999px | 头像、状态点、胶囊标签 |

同一层级必须同圆角：卡片圆角 10px 时，卡片内按钮用 6px，不要跟着变大。

### 2.3 字号、行高、字重

控制台信息密度高，正文基准 **13px**（不是 16px）：

| token | 值 | 用途 |
|---|---|---|
| `--wa-text-xs` | 11px | 辅助标注、类型标签、计数 |
| `--wa-text-sm` | 12px | 次要说明、表头、元信息 |
| `--wa-text-base` | 13px | 正文、列表主文本、按钮 |
| `--wa-text-md` | 14px | 段落正文、弹窗说明 |
| `--wa-text-lg` | 16px | 区块标题、弹窗标题 |
| `--wa-text-xl` | 20px | 页面标题（一页最多一个） |

- 行高：标题 `--wa-leading-tight`（1.35），正文 `--wa-leading-normal`（1.55），长说明文字 `--wa-leading-relaxed`（1.7）。
- 字重只用 400 / 500 / 600。600 仅用于标题与选中项的名称，**不要用加粗表达选中**（选中靠边框 + 底色 + 勾）。
- 禁止 12.5px、12.8px 这类非整数值。

### 2.4 图标

- 跟随 Semi 图标集（`@douyinfe/semi-icons`），尺寸与所在文本行对齐：12px 图标配 12–13px 文本，16px 图标配 14–16px 文本。
- 纯图标按钮必须同时给 `aria-label` 与 `title`。
- **类型标识统一走 `PluginVisual.tsx`**：新增插件类型要同时补三处，缺一处就会出现"白底白字"或"无色块"：

| 位置 | 文件 |
|---|---|
| 类型联合与中文名 `KIND_LABEL` | `web/src/components/PluginVisual.tsx` |
| 图标映射 `KindIcon` | 同上 |
| 类型色：`--plugin-tint`（小尺寸）+ `background` 渐变（大尺寸） | `web/src/styles.css` 的 `.plugin-icon-<kind>` |

- 自绘图标没有 Semi 内置的 `.semi-icon` 类，**不会自动获得 8px 右间距**，需要在所属容器里补：

```css
.space-tree .semi-tree-option-label .plugin-icon { margin-right: var(--wa-space-8); }
```

## 3. 颜色与主题

### 3.1 只用语义 token，不写色值

```css
/* 对 */
color: var(--semi-color-text-1);
background: var(--semi-color-fill-0);
border: 1px solid var(--semi-color-border);

/* 错 */
color: #9ca3af;
background: rgba(255, 255, 255, 0.04);
```

语义映射（深色主题下由 Semi 自动切换，不要自己判断主题）：

| 场景 | token |
|---|---|
| 页面底 | `--semi-color-bg-0` |
| 面板/卡片 | `--semi-color-bg-1` |
| 悬浮层/弹窗 | `--semi-color-bg-2` |
| 弱填充（提示块、hover） | `--semi-color-fill-0` / `fill-1` |
| 分割线、描边 | `--semi-color-border` |
| 主文本 / 次文本 / 弱文本 / 占位 | `--semi-color-text-0` / `-1` / `-2` / `-3` |
| 成功 / 警告 / 危险 / 主色 | `--semi-color-success` / `warning` / `danger` / `primary` |
| 主色浅底（选中态） | `--semi-color-primary-light-default` |

现状里仍有二十余处硬编码色值（品牌色覆盖、插件类型渐变属例外）。**新增代码零新增**，改动碰到旧代码时顺手替换。

### 3.2 品牌色只在核心主题位置覆盖

只允许在 `body[theme-mode='dark']` 覆盖 `--semi-color-primary*`（已有实现）。不要在各组件里改主色，否则同一个按钮在不同页面颜色不同。

### 3.3 对比度（硬指标，WCAG 2.1 AA）

- 正文文本 ≥ **4.5:1**；大文本（≥18.66px 粗体或 ≥24px）≥ 3:1。
- 图标、边框、焦点环等 UI 元素与图形 ≥ **3:1**。
- 禁用态可以低于该值，但必须仍看得出"这里有内容、只是不可用"（通常用 `opacity: .5~.6`，不要直接隐藏）。

### 3.4 类型色只用于图标

插件类型色是"分类标识"，不是语义色，按尺寸分两种出口：

| 场景 | 表现 | 依据 |
|---|---|---|
| ≥24px（卡片、列表、弹窗选项） | 实心渐变底 + 白色图标，`background` 在 `.plugin-icon-<kind>` | 面积够，色块能承担识别 |
| <24px（树节点、行内徽标） | **不放色块**，用 `--plugin-tint` 给单色图标着色 | 16px 塞实心块会糊，且与同层灰色单色图标风格冲突 |

- 两种出口共用同一组类型色，新增类型时 `--plugin-tint` 与 `background` 一起补。
- 类型色**不用于文字、边框、进度条**。语义色（成功/警告/危险）只表达状态，不表达分类。

## 4. 布局

### 4.1 页面骨架

- 左侧导航固定宽度（当前 260px 量级），右侧内容区自适应，`min-width: 0` 必须写在 flex 子项上，否则长文本会把布局撑破。
- **水平内边距由分区容器自己带，且同页统一为 20px**（`--wa-space-20`）：头部 `16px 20px`、会话网格 `20px`、插件面板 `20px`。不要指望父级统一给，也不要在某个分区里省掉——否则它的标题会缩进 20px、旁边区块没有，一眼就能看出错位。
- 只有分隔线（`border-top`）没有内边距的分区是最常见的贴边来源，加 `border-top` 时同一条规则里把 `padding` 一起写。
- **一屏只留一个纵向滚动容器**：滚动放在面板根节点（`.session-panel`），各分区按自然高度排布、自身不滚。否则底部区块会被父级 `overflow: hidden` 裁掉、还滚不到（插件面板踩过：插件一多，末行直接消失）。
- 会随滚动消失的固定分区（头部、工具条）用 `position: sticky; top: 0` + 不透明背景；同时给 `flex: none` 防止被压缩。
- 滚动容器内的分区一律 `flex: none`（或 `flex: 0 0 auto`），让内容决定高度；只有需要「占了剩余空间」的区域才用 `flex: 1`。
- 卡片列表网格自身不设固定高度。
- 网格卡片一律"行高由内容决定"，否则卡片会被 flex 压扁并裁掉底部操作区：

```css
.card-grid { grid-auto-rows: max-content; align-content: start; }
.card { height: auto; overflow: visible; }   /* 覆盖 Semi Card 默认 overflow:hidden */
```

### 4.2 空、加载、错误

任何"会拉数据的区域"必须显式处理四态，缺一不可：

| 态 | 表现 |
|---|---|
| 加载 | 骨架或 `Spin`，区域高度与内容态接近，避免跳动 |
| 空 | 居中：一句话说明 + 一句下一步 + 一个主操作（能做的事） |
| 错误 | 说明发生了什么 + 可重试按钮；不要只弹 Toast 就留白 |
| 禁用/只读 | 弱化但保留结构；用说明文字解释为什么不可用，而不是让入口凭空消失（权限决定是否显示入口，状态决定是否可点） |

## 5. 组件模式

### 5.1 按钮

| 层级 | Semi 写法 | 用途 |
|---|---|---|
| 主操作 | `theme="solid"` | 每屏/每弹窗最多一个 |
| 次操作 | `theme="light"` / 默认 | 常规动作 |
| 幽灵 | `theme="borderless"` | 工具栏、行内图标 |
| 危险 | `type="danger"` | 删除、卸载、重置 |

- 同一行按钮：**取消在最左、主操作在最右**，顺序永不倒置。
- 加载态只锁主按钮（`loading`），不要全屏遮罩。
- 二次确认只给"不可恢复"的操作；可恢复的用撤销。

### 5.2 表单字段

- 结构固定：`标签（上） → 控件（下） → 错误（下）`，标签与控件间距 `--wa-space-6`，字段组之间 `--wa-space-16`。
- 必填标 `*`，选填写"选填"弱化标注；**全必填时不标星**（噪音），全选填时不标"选填"。
- 校验在**提交时**触发，或失焦后触发；错误文案写"怎么解决"，不写"输入不合法"。
- 占位符只做示例（`如：订单查询`），不承担标签职责。
- 可选值 ≤ 6 且需要解释时，用卡片选择而不是下拉（见 5.4）。

### 5.3 对话框

| 项 | 规则 |
|---|---|
| 宽度 | 单字段 520（Semi 默认）；带选项卡片或两列 560；复杂表单 720 |
| 顶部 | 一句话说明背景（左侧主色竖条 + `fill-0` 底），与字段区分开 |
| 动作区 | 固定在底部，取消左、主操作右，只有一个主操作 |
| 校验失败 | **不关闭弹窗**，字段标红 + 内联错误，保留用户输入 |
| 危险操作 | 主按钮 `type="danger"`，标题/正文说清影响范围（"删除后不可恢复，其中的文件一并删除"） |
| 错误行 | 预留固定高度（`min-height: 18px`），出现错误时弹窗不跳动 |

### 5.4 分类选择：卡片还是下拉？

判断标准是"用户在选身份，还是在填值"：

- **选身份**（建什么类型、装到哪类空间）：用卡片阵列，每张卡是「图标 + 名称 + 一句话语义」。用户需要比较，下拉会把选项藏起来。
- **填值**（数量、模板名、已确定的枚举）：用下拉/单选。

卡片选择的实现要求：

- 两列网格，`min-height` 一致，文字最多两行；
- 选中态 = 主色边框 + `primary-light-default` 底 + 右上角勾；hover 只改边框；`:focus-visible` 有 2px 主色 outline；
- 语义提示必须写清"做什么"，而不是重复类型名；
- 键盘按 `radiogroup` 实现：`role="radio"` + `aria-checked` + roving `tabIndex`（选中项 0、其余 -1），方向键切换并移动焦点。

参考实现：`SpaceDialog.tsx` 的 `.plugin-kind-option` 与 `styles.css` 的 `.plugin-kind-grid`。

## 6. 交互与可访问性

- **焦点可见**：所有可交互元素都要 `:focus-visible` 样式，禁止全局 `outline: none`。
- **键盘**：Tab 顺序与视觉顺序一致；弹窗内焦点不逃逸；Esc 关闭（有未保存改动时先确认）。
- **触控目标**：桌面端可点区域 ≥ 24×24px（WCAG 2.2 AA 2.5.8），图标按钮靠 padding 撑开，不要只靠 16px 图标本身。
- **动效**：只用于状态切换（hover、展开、选中），时长 `--wa-duration-fast` / `--wa-duration-base`，缓动 `--wa-ease`；不要给布局变化加长动画。
- **文案**：按钮用动词（"创建""卸载"），标题用名词短语（"新建插件"），错误说清后果。

## 7. 代码约定

- 类名 `kebab-case`，格式 `<区域>-<元素>[-<变体>]`：`.space-tree`、`.plugin-kind-option`、`.resource-card-desc`。
- 状态类统一 `.is-*`：`.is-active`、`.is-loading`、`.is-disabled`。不用 `.active`、`.on` 这类裸词。
- 组件内联 `style` 只用于动态计算值（宽度、坐标），静态样式一律进 `styles.css` 对应区域。
- 新增 CSS 追加到对应分区注释下（`/* ---- 弹窗 ---- */` 等），不要堆在文件末尾。
- 深色是唯一主题，不需要写浅色分支。

## 8. 反模式（都是本项目真实踩过的）

1. **自绘图标紧贴文字**：Semi 的 8px 间距只作用于 `.semi-icon`，自定义 span 要自己补 margin。
2. **用下拉承载分类选择**：六个纯文字选项摆在 Select 里，用户无法判断"技能"和"组件"差在哪。
3. **只读状态只在顶层计算**：`plugins/<slug>` 是只读，但它的 `references/` 子目录没继承，子目录上仍出现新建/删除入口，且后端也没拦。**权限与只读判定必须整棵继承，且只在一处判定、后端兜底。**
4. **新增枚举只改一半**：加了 `agent`/`source` 类型，`KIND_LABEL` 有了、`.plugin-icon-agent` 没写，图标白底白字。**枚举必须三处同步（见 2.4）。**
5. **卡片被 flex 压扁**：网格放在限高容器里、卡片沿用 Semi 的 `overflow: hidden`，底部操作区被裁掉。**行高由内容决定，卡片不设固定高度。**
6. **用加粗表达选中**：选中项加粗会让整块文字跳动，改用边框 + 底色 + 勾。
7. **删除后只刷一部分缓存**：删目录、改名后文件树不失效，指向不存在的文件。**数据变更按 queryKey 全域失效，且清理失效的 URL 参数。**
8. **小尺寸塞实心高饱和色块**：16px 的树节点里放渐变方块 + 白图标，白色字形糊成一团、还抢注意力，与同层灰色线框图标格格不入。**小尺寸用着色线框，实心块只给 ≥24px。**
9. **分区只加分隔线不给内边距**：插件面板只写了 `margin-top` + `border-top`，标题、刷新按钮、空态全部贴边，和上方 20px 缩进的会话网格明显错位。**加分隔线时同步给 `padding: var(--wa-space-20)`。**

## 9. 评审清单

提交 UI 改动前逐条过：

- [ ] 间距、圆角、字号全部来自 token，没有新裸值
- [ ] 没有新增硬编码色值；颜色全用 `--semi-color-*`
- [ ] 一屏/一弹窗只有一个 solid 主按钮，取消在左
- [ ] 加载/空/错误/只读四态都有（至少不白屏）
- [ ] 图标按钮有 `aria-label`；键盘可操作；`:focus-visible` 可见
- [ ] 文本对比度 ≥ 4.5:1，UI 元素 ≥ 3:1
- [ ] 新增枚举类型时，`KIND_LABEL` / `KindIcon` / `.plugin-icon-<kind>` 三处齐全
- [ ] 长文本（中文、slug、英文词）不撑破容器（`min-width: 0` / `overflow-wrap`）
- [ ] 弹窗校验失败不关闭、错误内联、弹窗高度不跳
- [ ] CSS 落在对应分区注释下，类名符合 `<区域>-<元素>` 与 `.is-*`
